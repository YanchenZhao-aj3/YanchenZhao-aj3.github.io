#### 框架二：Spring RestTemplate / WebClient (主流之选)
**优点**：Spring 生态标配，代码量大幅减少，自动处理JSON编解码和长连接池。WebClient对高并发支持好。
**缺点**：需要引入spring-boot-starter-webflux（对于WebClient），且默认不包含AI模型的特殊处理。

**伪代码示例：**
java
@Autowired
private WebClient.Builder webClientBuilder;

private final String baseUrl = "https://www.yunwuai.cc/v1";
private final String apiKey = "你的云雾API Key";

public Flux<String> chatCompletion(String message) {
    // 构建请求体，里面包含流式参数
    String requestBody = "{\"model\": \"llama4-chat\", \"stream\": true, ...}";
    return webClientBuilder.baseUrl(baseUrl)
            .defaultHeader("Authorization", "Bearer " + apiKey)
            .build()
            .post()
            .uri("/chat/completions")
            .bodyValue(requestBody)
            .retrieve()
            .bodyToFlux(String.class);
}

**编辑成本**：代码三层式，但需要理解Reactive Stream。最大的优势是复用云雾接口的兼容性，无需修改任何框架原生逻辑。调用费用依然按云雾的1元=1美元计。
