### 第三步：写代码

在项目目录下创建一个 `index.js` 文件，把下面这段代码贴进去。注意替换 `YOUR_API_KEY` 为你第一步复制的 API Key。

javascript
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'https://www.yunwuai.cc/v1',  // 关键：改成云雾的 API 地址
  apiKey: 'YOUR_API_KEY'                 // 你从云雾获得的 API Key
});

async function main() {
  const stream = await openai.chat.completions.create({
    model: 'gemini-2.5-flash-lite',      // 要调用的模型
    messages: [
      { role: 'user', content: '用一句话解释什么是量子计算？' }
    ],
    stream: true,                         // 流式输出
  });

  for await (const chunk of stream) {
    process.stdout.write(chunk.choices[0]?.delta?.content || '');
  }
}

main();


这段代码做了几件事：

- 用云雾的 baseURL 连接你的 API Key。
- 指定模型为 `gemini-2.5-flash-lite`。
- 向模型发送一个问题，并以流式方式接收回答。
- 实时打印出回复内容。

注意代码里 `model` 字段写的是 `gemini-2.5-flash-lite`。如果你不确定云雾平台上这个模型的具体名称，可以去官网的模型列表里查看。

### 第四步：运行并看到结果

如果你的终端里输出了一坨错误信息，先检查这三件事：
