我习惯用 `okhttp3` 发流式请求，但为了展示“低代码”，我直接用标准库的 `HttpClient`：

java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.net.http.HttpRequest.BodyPublishers;

public class Llama4QuickTest {
    public static void main(String[] args) throws Exception {
        // 1. 核心：改 base_url 为自己的 API 地址
        String baseUrl = "https://www.yunwuai.cc/v1";
        // 2. 核心：用你的 API key
        String apiKey = "your-cloud-mist-api-key";
        
        String requestBody = "{\n" +
                "  \"model\": \"meta-llama/Llama-4-8B-Instruct\",\n" +
                "  \"messages\": [{\"role\": \"user\", \"content\": \"你好，请用中文回答：什么是低代码开发？\"}]\n" +
                "}";

        // 3. 核心：发送请求（和 OpenAI 完全兼容）
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(baseUrl + "/chat/completions"))
                .header("Authorization", "Bearer " + apiKey)
                .header("Content-Type", "application/json")
                .POST(BodyPublishers.ofString(requestBody))
                .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}


你看，**核心改动就两个点**：
1. 把 `base_url` 从 `https://api.meta.ai/v1` 换成 `https://www.yunwuai.cc/v1`。
2. 把官方 API key 换成云雾的 key。

其他所有东西——JSON 格式、消息结构、返回参数——完全兼容 OpenAI 标准。这意味着你用 OpenAI 写的 LangChain、Spring AI、或者自定义封装类，**无缝迁移**。
