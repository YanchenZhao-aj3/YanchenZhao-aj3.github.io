### Step 2：创建低代码应用并找到“HTTP请求”组件

进入你的低代码平台，创建一个新的应用。通常这个平台的组件库里会有一个叫 **“HTTP请求”、“API请求”或“RESTful API”** 的组件。把它拖到你的页面逻辑中。

### Step 3：配置API端点

在你的低代码应用里，找到与AI对话的页面，比如一个聊天框。在聊天框的“提交”按钮逻辑中，配置你的HTTP请求。

*   **请求地址 (URL)**：这里就是关键一步。设置为：`https://www.yunwuai.cc/v1/chat/completions`
*   **请求方法 (Method)**：选择 `POST`。
*   **请求头 (Headers)**：
    *   添加一个 `Authorization`，值为 `Bearer [你的云雾ai API Key]`。
    *   添加一个 `Content-Type`，值为 `application/json`。

### Step 4：发送请求体

在请求体（Body）的文本框中，输入标准的OpenAI格式的JSON。例如：

json
{
  "model": "gpt-4o-mini",
  "messages": [
    {
      "role": "user",
      "content": "你是一名称职的助手，请用诙谐幽默的语气回答用户的问题。我的问题是：中国的首都是哪里？"
    }
  ]
}


### Step 5：处理返回数据

这个HTTP请求组件会返回一个JSON数据。你需要在这个组件的 **“成功回调”**  中，编写一个简单的表达式来提取“AI的回答”：
*   通常返回数据的结构是 `response.choices[0].message.content`。
*   你把这个值绑定到页面上的一个文本组件上，页面就会展示出AI的回答。
