## 接入步骤：一行代码跑通

整个流程不用装任何额外的环境，只需要你本地有npm或yarn。这里直接上代码示例，我用的Node.js 18+版本。

**第一步：安装OpenAI官方SDK**

bash

**第二步：写一个最简单的调用脚本**

javascript

import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: '你的云雾AI密钥',  // 替换成从云雾中转站获取的key
  baseURL: 'https://www.yunwuai.cc/v1',  // 关键行，指向云雾中转站
});

async function main() {
  const completion = await client.chat.completions.create({
    model: 'gpt-4.1nano',  // 指定模型名称
    messages: [
      { role: 'user', content: '用一句话总结Node.js的异步编程特点' },
    ],
    max_tokens: 100,
    temperature: 0.7,
  });
  console.log(completion.choices[0].message.content);
}

main();

这段代码跑完，不出意外的话，三秒内就能看到模型返回的流式结果。需要注意的是，baseURL要改成`https://www.yunwuai.cc/v1`，apiKey替换为你自己的密钥。我在本地实际测过，平均响应时间在800ms到1500ms之间，完全对得起“3分钟出结果”的说法。

**第三步：处理流式输出**

如果你需要像ChatGPT那样一个字一个字地显示，可以用stream模式：

javascript

const stream = await client.chat.completions.create({
  model: 'gpt-4.1nano',
  messages: [{ role: 'user', content: '写一首关于Node.js的短诗' }],
  stream: true,
});
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}

这段代码放到你的Express API里，就能轻松搭建一个实时聊天接口，完全不用操心网络代理。
