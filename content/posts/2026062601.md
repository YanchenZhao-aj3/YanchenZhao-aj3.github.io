## 进阶技巧：如何安全使用密钥

上面我们直接把密钥写死在代码里，这对快速测试来说是没问题的。但如果你想把代码上传到GitHub或者分享给别人，这样做无异于把银行卡密码写在钱包外面。

**推荐做法**：使用环境变量。

1.  在项目文件夹中创建一个 `.env` 文件（注意前面的点不要省略）。
2.  在文件里写入：
    
    API_KEY=你的密钥字符串
    BASE_URL=https://www.yunwuai.cc/v1
    
3.  安装一个库：`pip install python-dotenv`
4.  修改代码，改为读取环境变量：

python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    base_url=os.getenv("BASE_URL"),
    api_key=os.getenv("API_KEY")
)

# 后续调用不变


这样，即使你的代码仓库被公开，别人也无法获得你的密钥。同时，记得把 `.env` 文件添加到 `.gitignore` 里。
