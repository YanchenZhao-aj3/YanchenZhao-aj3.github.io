## 用代码演示多模态能力

Claude Opus 4.1的一个巨大进步是它对多模态的强大支持。下面这段代码演示了如何让Claude Opus 4.1分析一张图片并理解代码。

python
import openai
import base64

openai.base_url = "https://www.yunwuai.cc/v1"
openai.api_key = "your-api-key"

# 假设我们有一张项目代码截图，我们需要Claude来解释它
def encode_image(image_path):
    with open(image_path, "rb") as image_file:
        return base64.b64encode(image_file.read()).decode('utf-8')

image_path = "path_to_your_code_screenshot.png"
base64_image = encode_image(image_path)

response = openai.chat.completions.create(
    model="claude-opus-4-1",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "请分析这张代码截图，找出其中可能存在的Bug，并给出改进建议。"},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{base64_image}"}}
            ]
        }
    ],
    max_tokens=1000
)

print(response.choices[0].message.content)


这样改一行`base_url`，你的代码就可以用上Claude最新的视觉能力——这在传统方式下需要下载复杂的Boto3 SDK，或者自己搭建Anthropic的认证体系，现在十行代码就能搞定。
