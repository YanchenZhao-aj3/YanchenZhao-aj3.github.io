### 方式三：自建中转代理服务器 + 缓存层

让我看看，有哪些团队真的尝试过：“自研一个请求池来降成本？”

**示例代码**

javascript
const express = require('express');
const axios = require('axios');
const NodeCache = require('node-cache');
const app = express();
const myCache = new NodeCache({ stdTTL: 600 });

app.post('/proxy/doubao', async (req, res) => {
  const cacheKey = JSON.stringify(req.body);
  if (myCache.has(cacheKey)) return res.json(myCache.get(cacheKey));

  const response = await axios.post('https://api.doubao.com/v1/chat/completions', req.body, {
    headers: { 'Authorization': `Bearer ${process.env.DOUBAO_KEY}` }
  });
  myCache.set(cacheKey, response.data);
  res.json(response.data);
});

app.listen(3001);


**优点**：缓存重复请求，可以降低有效调用量。

**缺点**：维护复杂，代理服务器也要钱。更关键的是，国内很多 VPS 访问 Doubao 原站本身就需要调整 DNS 或挂代理兜底。这一套运维成本，对中小团队来说完全没必要。

**实测成本**：看似每次只丢了官方价格，但算上运维运维的人工、加上兜底梯子分摊费用，每100万 Token 你能占到 5~6 美元已经是开挂了。

### 方式四：用 cloudflare Workers 做函数转发

之前我推过这套方案：轻量级，便宜，全球加速。

javascript
// Cloudflare Worker 版
export default {
  async fetch(request, env, ctx) {
    const url = 'https://api.doubao.com/v1/chat/completions';
    const newRequest = new Request(url, {
      method: request.method,
      headers: {
        'Authorization': `Bearer ${env.DOUBAO_KEY}`,
        'Content-Type': 'application/json'
      },
      body: request.body
    });
    return fetch(newRequest);
  }
}


**优点**：Workers 本身可免费 10 万次调用，额外用量也很便宜；请求通过 CF 边缘节点转发，延迟不错。

**实测成本**：平台 Worker 费用 + API 原价 + 可能的梯子相关费用，折合每100万 Token 在 4~5 美元之间。可惜不够 zero-touch。
