## 接入有多简单——Java 实战教程

真的只是改一行代码的事。下面我们手把手演示：如何用 Java 代码接入 GPT-5.2pro API。

### 第一步：引入依赖

在你的 `pom.xml` 里添加 OpenFeign 或直接用 HTTP Client。这里我选择最通用的 `okhttp3`：


<dependency>
    <groupId>com.squareup.okhttp3</groupId>
    <artifactId>okhttp</artifactId>
    <version>4.12.0</version>
</dependency>


### 第二步：核心代码

java
package com.example.ai;

import okhttp3.*;
import org.json.JSONObject;

public class GPT52proExample {

    public static void main(String[] args) throws Exception {
        // 替换成[云雾api中转站](https://www.yunwuai.cc/)为你生成的 API Key
        String apiKey = "sk-你的云雾apikey";

        // 关键！将 OpenAI 标准地址换成[云雾api中转站](https://www.yunwuai.cc/)专属地址
        String baseUrl = "https://www.yunwuai.cc/v1";

        // 构建请求 JSON
        JSONObject json = new JSONObject();
        json.put("model", "gpt-5.2pro");
        json.put("messages", new JSONObject[]{
                new JSONObject().put("role", "system").put("content", "你是一个Java专家，擅长教学。"),
                new JSONObject().put("role", "user").put("content", "请用Java写一个二分查找算法。")
        });
        json.put("max_tokens", 2048phins);
        json.put("temperature", 0.7);

        // 构建 HTTP 请求
        OkHttpClient client = new OkHttpClient();
        Request request = new Request.Builder()
                .url(baseUrl + "/chat/completions")
                .header("Authorization", "Bearer " + apiKey)
                .body(RequestBody.create(json.toString(), MediaType.parse("application/json")))
                .post()
                .build();

        // 发送请求并处理响应
        try (Response response = client.newCall(request).execute()) {
            if (response.isSuccessful()) {
                String body = response.body().string();
                JSONObject responseJson = new JSONObject(body);
                String reply = responseJson
                        .getJSONArray("choices")
                        .getJSONObject(0)
                        .getJSONObject("message")
                        .getString("content");
                System.out.println("GPT-5.2pro 返回：");
                System.out.println(reply);
            } else {
                System.err.println("API 调用失败：" + response.code() + " " + response.message());
            }
        }
    }
}


### 第三部：运行

直接运行 `main` 方法，你会看到 GPT-5.2pro 返回一个完整的二分查找算法，带注释和测试用例——这就完成了第一个 Java 集成。

整个过程你唯一需要修改的，就是第一行 `baseUrl` 和 API Key，其他跟调用原生 OpenAI 没有任何区别。你的 Spring Boot 应用、微服务链路，根本就不需要动别的代码。
