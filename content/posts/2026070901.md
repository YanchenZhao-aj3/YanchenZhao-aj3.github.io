## 方式二：用Spring Boot低代码接入云雾

如果你在用Spring Boot做微服务，接入更简单——写一个配置类，然后到处用`RestTemplate`或`WebClient`调用即可。

**第一步：在application.properties配置**

properties
yunwu.api.base-url=https://www.yunwuai.cc/v1
yunwu.api.key=sk-yunwu-your-key-here
yunwu.api.model=gpt-5-mini


**第二步：写一个配置类，创建AIService Bean**

java
@Component
public class YunwuAIConfig {
    @Value("${yunwu.api.base-url}")
    private String baseUrl;
    
    @Value("${yunwu.api.key}")
    private String apiKey;
    
    @Bean
    public OpenAiService yunwuAiService() {
        OpenAiService service = new OpenAiService(apiKey, 60);
        service.setBaseUrl(baseUrl);
        return service;
    }
}


**第三步：在Controller里注入Service**

java
@RestController
public class ChatController {
    @Autowired
    private OpenAiService yunwuAiService;
    
    @PostMapping("/chat")
    public String chat(@RequestBody String message) {
        ChatCompletionRequest request = ChatCompletionRequest.builder()
            .model("gpt-5-mini")
            .messages(List.of(new ChatMessage("user", message)))
            .maxTokens(500)
            .build();
        
        return yunwuAiService.createChatCompletion(request)
            .getChoices()
            .get(0)
            .getMessage()
            .getContent();
    }
}
