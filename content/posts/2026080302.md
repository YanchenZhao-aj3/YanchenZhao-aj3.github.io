上面我们讲过，只需改一行 `baseUrl`。现在用一个完整的 Java 类来演示。

### 2. 核心调用代码

java
import com.theokanning.openai.completion.chat.ChatCompletionRequest;
import com.theokanning.openai.completion.chat.ChatMessage;
import com.theokanning.openai.completion.chat.ChatMessageRole;
import com.theokanning.openai.service.OpenAiService;
import java.time.Duration;
import java.util.List;

public class NanoApiDemo {
    public static void main(String[] args) {
        // 1. 配置：换成[云雾api中转站](https://www.yunwuai.cc/)的 Base URL 和 Key
        String baseUrl = "https://www.yunwuai.cc/v1";
        String apiKey = "sk-你的云雾API Key";   // 从云雾后台创建

        // 2. 创建 OpenAiService 实例，传入自定义地址
        OpenAiService service = new OpenAiService(baseUrl, apiKey, Duration.ofSeconds(30));
        
        // 3. 构造请求：明确指定 gpt-4.1-nano
        ChatCompletionRequest request = ChatCompletionRequest.builder()
                .model("gpt-4.1-nano")   // 模型名
                .messages(List.of(
                    new ChatMessage(ChatMessageRole.SYSTEM.value(), "你是一个专业的Java开发助手"),
                    new ChatMessage(ChatMessageRole.USER.value(), "请用Java写一个单例模式，要求线程安全。")
                ))
                .temperature(0.7)
                .maxTokens(1024)
                .build();
        
        // 4. 执行调用
        String result = service.createChatCompletion(request)
                .getChoices().get(0).getMessage().getContent();
        
        System.out.println("模型回复：\n" + result);
        
        // 5. 释放资源
        service.shutdownExecutor();
    }
}


### 3. 什么时候需要额外配置？
- **流式输出**：可以将 `.maxTokens()` 改为 `.stream(true)`，然后配置 SSE 事件处理。
- **多轮对话**：只需在 `messages` 列表里追加历史消息。
- **并发请求**：Java 开发者可以直接用多线程，[云雾api中转站](https://www.yunwuai.cc/)支持高并发，不需要额外排队。

这段代码放在你的 Spring Boot 项目或纯 Java 应用中都能直接跑通，不需要科学上网。
