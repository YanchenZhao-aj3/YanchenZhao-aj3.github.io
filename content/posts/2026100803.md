## 第二步：获取并运行 Java 示例（核心！手把手教学）

### 前提条件
- 你的项目使用 **Java 11+**。
- 你已配置好 **Maven** 或 **Gradle**。

### 1. 创建 Maven 项目并添加依赖

在你的 `pom.xml` 文件中，添加 Google Cloud AI Platform 的 SDK 依赖：

xml
<dependency>
  <groupId>com.google.cloud</groupId>
  <artifactId>google-cloud-aiplatform</artifactId>
  <version>3.54.0</version>
</dependency>


**注意点：** 确保你的项目里没有其他的 Google Cloud 认证 SDK（如 `google-cloud-core`）冲突。

### 2. 编写 GeminiProExample.java

创建新类 `GeminiProExample.java`，复制以下代码。**这里最关键的一行是设置 `endpoint`，我们把它指向云雾中转站的地址，而不是 Google 的官方地址。**

java
import com.google.cloud.aiplatform.v1beta1.*;
import com.google.protobuf.Value;
import com.google.protobuf.util.JsonFormat;
import java.io.IOException;
import java.util.List;

public class GeminiProExample {

    // !! 关键配置：将 endpoint 设置为[云雾api中转站](https://www.yunwuai.cc/)的 Gemini 专用地址
    // !! 注意：最后有 '/v1' 后缀
    private static final String ENDPOINT = "https://www.yunwuai.cc/v1";
    // 你的云雾 API Key
    private static final String API_KEY = "YOUR_YUNWU_API_KEY_HERE"; // 替换为你的密钥

    public static void main(String[] args) throws IOException {
        // 1. 设置客户端
        // 注意：Google 官方 SDK 通常需要项目 ID，但云雾中转站做了处理，
        // 我们可以通过设置环境变量或直接在客户端上指定 API Key。
        // 最简便的方式：在客户端上设置 API Key。
        
        // 使用 ApiKeyCredentials
        ApiKeyCredentials credentials = ApiKeyCredentials.create(API_KEY);
        PredictionServiceSettings settings = PredictionServiceSettings.newBuilder()
                .setEndpoint(ENDPOINT) // 指向中转站地址
                .setCredentialsProvider(() -> credentials)
                .build();

        try (PredictionServiceClient client = PredictionServiceClient.create(settings)) {
            // 2. 构建请求
            // Gemini Pro 模型名称：在云雾中转站上对应的模型名是 "gemini-pro"
            String model = "publishers/google/models/gemini-pro";
            
            // 构建消息内容
            String prompt = "请用中文介绍一下你自己。";
            Content content = Content.newBuilder()
                    .setRole("user")
                    .addParts(Part.newBuilder().setText(prompt).build())
                    .build();

            // 3. 发送请求
            GenerateContentRequest request = GenerateContentRequest.newBuilder()
                    .setModel(model)
                    .addContents(content)
                    .build();

            // 4. 获取并打印响应
            GenerateContentResponse response = client.generateContent(request);
            for (Candidate candidate : response.getCandidatesList()) {
                for (Part part : candidate.getContent().getPartsList()) {
                    System.out.println("Gemini Pro 回复: " + part.getText());
                }
            }
        } catch (Exception e) {
            System.err.println("调用失败: " + e.getMessage());
            e.printStackTrace();
        }
    }
}
