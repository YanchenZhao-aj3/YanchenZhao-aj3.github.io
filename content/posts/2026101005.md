#### Step 5：进阶：想把图片存在本地传上去？

别怕，也很简单。用Python的base64库，把你的图片“装进”请求里。

python
import base64
import os

def encode_image(image_path):
    with open(image_path, "rb") as image_file:
        return base64.b64encode(image_file.read()).decode("utf-8")

# 图片路径（假设你的图叫：mydog.jpg）
base64_image = encode_image("mydog.jpg")

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://www.yunwuai.cc/v1"
)

response = client.chat.completions.create(
    model="qwen-vl-plus",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {
                        "url": f"data:image/jpeg;base64,{base64_image}"
                    }
                },
                {
                    "type": "text",
                    "text": "这只狗是不是看起来很开心？用中文回答。"
                }
            ]
        }
    ],
    max_tokens=300
)

print(response.choices[0].message.content)


**避坑指南**：Base64字符串很长，别直接写在代码里。用函数读文件，或者用`with open`读。另外，大图（超过10MB）建议先压缩再传，模型输入有分辨率范围限制。
