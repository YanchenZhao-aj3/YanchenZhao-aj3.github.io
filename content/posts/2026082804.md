### 第三步：写你的Node.js代码

在项目根目录下创建一个`index.js`文件，然后把下面这段代码复制进去。我已经把关键改动点标红了：

javascript
// index.js
import OpenAI from "openai";

const openai = new OpenAI({
  // 关键点1：把官方URL改成云雾的国内直连地址
  baseURL: "https://www.yunwuai.cc/v1", 
  // 关键点2：把这里换成你在云雾官网申请的API Key
  apiKey: "你的云雾API-KEY", 
});

async function main() {
  // 关键点3：指定模型为智谱清言。
  // 云雾支持智谱全系模型，比如glm-4-flash、glm-4-air、glm-4-plus等
  // 这里用轻量版glm-4-flash做演示
  const stream = await openai.chat.completions.create({
    model: "glm-4-flash",
    messages: [
      { role: "system", content: "你是一位资深的Node.js开发者。你的回答简洁、清晰，并且带有代码示例。" },
      { role: "user", content: "请用Node.js写一个简单的HTTP服务器，并返回'Hello World'。" },
    ],
    stream: true, // 开启流式输出，体验更好
  });

  for await (const chunk of stream) {
    // 解析流式数据，直接打印到控制台
    process.stdout.write(chunk.choices[0]?.delta?.content || "");
  }
}

main();


**注意！** 这个代码的`stream`模式是用来体验“机器打字”效果的。如果你想要一次性得到完整回复，把`stream: true`去掉，然后把遍历逻辑改成`const response = await openai.chat.completions.create(...)`，直接打印`response.choices[0].message.content`即可。这是智谱清言官方推荐的流式处理方式，云雾平台完美复刻。

很多新人照着网上的教程抄代码，但忘记处理`stream`模式。如果你开启了流式输出，**必须要用循环去读**，不然代码跑完了，控制台上一行字都没有，你还会以为自己写错了。上面的示例已经完美解决了这个问题。

云雾的API Key分为管理员Key和普通Key。如果你不小心设置了权限限制，比如只允许某个IP访问，那你用localhost调试时就可能报“认证失败”。注册后，直接创建一个**无IP限制**的Key最省事。

### 雷区4：网络环境问题
虽然云雾直连国内，但个别极其小众的内网环境（比如某些企业内部防火墙）仍可能会拦。确认一下你的终端能不能ping通`www.yunwuai.cc`。如果可以，那就没问题。
