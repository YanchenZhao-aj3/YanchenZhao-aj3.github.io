java
import com.openai.client.OpenAiClient;
import com.openai.client.okhttp.OpenAiOkHttpClient;
import com.openai.models.ChatCompletion;
import com.openai.models.ChatCompletionCreateParams;

public class OfficialDemo {
    public static void main(String[] args) {
        String apiKey = System.getenv("OPENAI_API_KEY");
        OpenAiClient client = OpenAiOkHttpClient.builder()
                .apiKey(apiKey)
                .build();

        ChatCompletionCreateParams params = ChatCompletionCreateParams.builder()
                .model("gpt-5-codex")
                .addUserMessage("写一个 Java 的快速排序算法")
                .maxCompletionTokens(500)
                .build();

        ChatCompletion completion = client.chat().completions().create(params);
        System.out.println(completion.choices().get(0).message().content().orElse(""));
    }
}


表面上看，代码没问题，但陷阱藏在这儿：

**陷阱一**：API 密钥管理。很多教程让你直接把 key 写死在代码里，或者用 `.env` 文件读取。一旦你的代码被 push 到公开仓库，key 被泄露，别人就能用你的额度疯狂调用，几分钟烧光你的余额。

**陷阱二**：`maxCompletionTokens` 参数设置不当。官方 Demo 经常保留 `maxCompletionTokens = 500` 但你不知道这个值实际上是“最多生成 500 个 token”。如果你刚好请求的 prompt 非常长，系统会直接在上下文中计算 token，而不会提醒你。一旦 `max_tokens` 超过实际需要，调用成本就直接翻倍。

**陷阱三**：隐形的“prompt 优化”开销。官方 SDK 在部分版本中会默认启用 prompt 压缩或缓存功能，这些功能会额外收费，但 Demo 不会告诉你。你每跑一次，可能就被多扣 10% 到 20% 的 Token 费用。

**陷阱四**：海外信用卡 + 科学上网。没有国内直连，每次调用 API 都需要挂代理，网络不稳定导致请求重发，每次重试都是真金白银。
