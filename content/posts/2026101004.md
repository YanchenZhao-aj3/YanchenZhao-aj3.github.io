在你的项目根目录下新建一个`gemini-demo.js`文件。注意，这里的关键就是替换`baseURL`。

javascript

#### 第三步：接入多模态（图片理解）

Gemini最强大的能力之一是原生多模态。你需要把本地图片转换成Base64编码传给它。

javascript
import OpenAI from "openai";
import fs from "fs";

const client = new OpenAI({
  baseURL: "https://www.yunwuai.cc/v1",
  apiKey: "你的API Key",
});

async function analyzeImage(imagePath) {
  const imageData = fs.readFileSync(imagePath);
  const base64Image = imageData.toString("base64");

  const response = await client.chat.completions.create({
    model: "gemini-2.5-pro",
    messages: [
      {
        role: "user",
        content: [
          { type: "text", text: "简述这幅图里发生了什么？" },
          { type: "image_url", image_url: { url: `data:image/jpeg;base64,${base64Image}` } },
        ],
      },
    ],
  });
  console.log(response.choices[0].message.content);
}

analyzeImage("./test.jpg");


注意：这里的`model`字段要对应云雾后台支持的Gemini模型ID，如`gemini-2.5-pro`或`gemini-2.5-flash`。

#### 第四步：流式输出（Stream）

让AI一个字一个字蹦出来，对用户体验很重要。代码改动极小：

javascript
const stream = await client.chat.completions.create({
  model: "gemini-2.5-pro",
  messages: [{ role: "user", content: "讲一个500字的冷笑话" }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || "");
}


流式输出国内直连，无延迟，非常快。

### 避坑清单：这些坑我替你踩过了

既然承诺附上“避坑清单”，下面是我在测试过程中遇到的5个最致命的问题及解决方案：

1. **网络超时或502**：部分用户反馈国内运营商DNS解析可能出问题。解决办法：在Node.js的`fetch`或`axios`配置中，给`baseURL`增加`timeout: 30000`（30秒超时）。云雾本身有美国、日本、香港等多地节点，但第一次连接可能会慢，耐心等待30秒，后续调用极快。

2. **模型名称错误**：不要随意用`gemini-pro`等旧名称。[云雾api聚合站](https://www.yunwuai.cc/)的模型列表已更新到2026年最新版本，务必在后台查看“模型支持”列表，使用最新的`gemini-2.5-pro`或`gemini-2.5-flash`。写错模型名会导致“404 Model not found”错误。

3. **API Key权限问题**：如果你在云雾后台购买了服务，但依然返回401或403，检查是否选择了正确的“分组”。Gemini模型建议选“限时特价”分组（费率0.6倍），这个分组的API Key和其他分组不通用。请重新生成对应分组的Key。

4. **缺少Content-Type标头**：在调用Gemini进行多模态（传图片）时，如果请求没有明确`Content-Type: application/json`，可能会出现解析错误。使用OpenAI SDK时通常自动处理，但如果自己用`axios`调用，务必手动设置请求头。

5. **上下文过长超出免费额度**：Gemini 2.5支持近100万Token上下文，但一次调用消耗Token巨大。云雾目前没有限制并发，但你的账户余额决定了能调用多少次。建议先用小文档测试，预估Token消耗。如果怕爆单，在代码中主动设置`max_tokens: 1000`来限制输出长度。
