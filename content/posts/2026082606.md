## 会碰到什么报错？怎么解决？

即使是最稳定的中转站，偶尔也可能因为网络抖动或余额问题报错。我给你们列几个常见问题和解决方案：

### 1. `AuthenticationError`
-   **场景**：Key 不对或 Key 过期。
-   **解决**：仔细检查你在代码里填的 `api_key`。或者，你可以每隔几分钟试着跑一次，如果失败，去官网后台重置一下 API Key。

### 2. `RateLimitError` (429 Too Many Requests)
-   **场景**：调用太过频繁（但云雾一般不限并发）。
-   **解决**：在请求之间加一个 `time.sleep(0.5)` 延缓调用节奏。

### 3. `APIConnectionError`
-   **场景**：网络未完全通顺，或者你的本地网络运营商干扰了 `api.openai.com` 的解析。
-   **解决**：确保你的 `base_url` 是 `https://www.yunwuai.cc/v1`，不是 `api.openai.com`。如果还报错，直接 ping 一下 `www.yunwuai.cc`，看能不能通。

### 4. “余额不足”
-   **场景**：云雾官方免费额度用完，也未充值。
